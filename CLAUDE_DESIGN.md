# Claude Design — Hermes Drop Checklist

This file tells you (or a fresh Claude Code session) exactly what to drop into Claude Design's "Set up your design system" wizard at https://claude.ai/design and where Claude Design's handoff bundles should land in this repo.

Convention reference: `~/code/CLAUDE_DESIGN.md` (global).

## Onboarding inputs

In the Claude Design wizard, fill these in:

- **Company name / design system**: `Hermes`
- **Blurb**: `Hermes is the self-improving AI agent built by Nous Research — a terminal-native agent with a built-in learning loop, scheduled automations, multi-platform messaging gateway, and a React 19 dashboard. Visual system: nocturnal teal canvas (Hermes Teal #041c1c), Hermes Cream (#ffe6cb) foreground, single warm amber top-left vignette, two-anchor palette, anti-skeuomorphic — depth comes from mix-blend-mode and a gated noise-grain layer rather than drop shadows. Built on the internal @nous-research/ui design system; seven shipped theme presets (default Hermes Teal, default-large, midnight, ember, mono, cyberpunk, rose).`

### Drop these (in order):

1. **DESIGN.md** (single file)
   - Path: `Hermes/DESIGN.md`
   - This is the 9-section design system spec — the most important input. Drop it first.

2. **Frontend folder** (drag-in-folder slot)
   - Path: `Hermes/web/src/`
   - Contains: `index.css` (the canonical token source — `:root` palette vars + `@theme inline` shadcn-compat token layer), `App.tsx` (shell + nav), `themes/presets.ts` (seven built-in theme palettes/typography/layout objects — also drop this even if it's nested), `components/` (Backdrop, NouiTypography, ChatSidebar, Toast, ModelPickerDialog, etc.), `pages/` (ChatPage, AnalyticsPage, ConfigPage, …), `lib/utils.ts` (the `cn` helper).
   - Skip `node_modules/` and any `dist/` outputs — Claude Design's selective copy will avoid these by default but verify.

3. **Brand assets** (drag-in-folder slot, or individual files)
   - **Local fonts (display)**: `Hermes/web/public/fonts/` — Collapse (Regular/Bold), Mondwest (Regular), RulesCompressed (Regular/Medium), RulesExpanded (Regular/Bold). These ship inside `@nous-research/ui` and are synced into `public/fonts/` by the `npm run sync-assets` script.
   - **Local fonts (terminal)**: `Hermes/web/public/fonts-terminal/` — JetBrains Mono (Regular/Bold/Italic), used by the embedded `/chat` xterm.js TUI.
   - **DS assets**: `Hermes/web/public/ds-assets/` — generated by `npm run sync-assets` from `node_modules/@nous-research/ui/dist/assets`. If the directory does not exist locally, run `npm run sync-assets` first (or skip and note `[needs-review]`).
   - **Favicon**: `Hermes/web/public/favicon.ico`
   - **Banner / README art** (optional): `Hermes/assets/banner.png` (referenced from `Hermes/README.md`).

### Skip

- **No `.fig` files** exist in this repo (confirmed via `find`). Skip the .fig slot.
- **No GitHub-link** input — we use local-folder drag for Hermes (per project convention).
- **`web/node_modules/`** — never drag this. The `@nous-research/ui` package is consumed via the published npm version (`^0.10.0`); its tokens are already inlined into `web/src/index.css` and `web/src/themes/presets.ts`.
- **`web/hermes_cli/web_dist/`** (Vite build output, see `vite.config.ts` `outDir`) — generated, skip.
- **`website/`** (Docusaurus docs site) — not part of the dashboard design system. Optional to drop if you want the docs marketing surface considered, but not required.
- **Top-level Python source** (`hermes/`, `agent/`, `gateway/`, `cli.py`, etc.) — backend, not visual.

## Receiving a Claude Design handoff bundle

When a design is ready in Claude Design, it produces a "handoff bundle" intended for Claude Code.

- **Land it here**: `Hermes/design/handoffs/<YYYY-MM-DD>-<short-name>/`
- **Then**: open a Claude Code session in this repo and ask it to apply the bundle. The session will know to look in `design/handoffs/` because of this file.
- **Gitignore**: add `design/handoffs/` to the repo `.gitignore` if you don't want bundle drafts committed (or commit them deliberately as a design log).

## Quick verify

After Claude Design's onboarding finishes, spot-check:

- Default canvas reads as **Hermes Deep Teal `#041c1c`**
- Default foreground/text reads as **Hermes Cream `#ffe6cb`**
- Warm vignette is **`rgba(255, 189, 56, 0.35)`** (top-left only, never per-component)
- Default sans stack starts with `system-ui, -apple-system, "Segoe UI"` (LENS_0 deliberately uses system fonts; only alternate themes override)
- Mono stack starts with `ui-monospace, "SF Mono", "Cascadia Mono"`; embedded TUI uses **JetBrains Mono** from `public/fonts-terminal/`
- Iconography is **lucide-react only**
- Anti-skeuomorphism is reflected: **no `box-shadow` defaults**; depth comes from `mix-blend-mode` (difference / lighten / plus-lighter / color-dodge) + the noise-grain SVG layer
- The seven theme presets show up: `default`, `default-large`, `midnight`, `ember`, `mono`, `cyberpunk`, `rose`

If any of those drift, edit `DESIGN.md` and re-run onboarding.
