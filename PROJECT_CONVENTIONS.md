# Hermes Project Conventions

Hermes conventions are seeded from `DESIGN.md` and `AGENTS.md`. The dashboard
uses token-driven Hermes Teal defaults; plugins and skills should stay concise,
tool-schema-first, and executable.

Resolve this pack with:

```bash
sdd conventions resolve --path . --surface plugin
```

The Hermes pack is project authority for Hermes work. Other project brands can
inspire gaps only when explicitly marked as inspiration.
